# Data directory

This folder holds the dataset used by CardioInsight AI.

## Current contents

**No real patient data is bundled.** When `CARDIOINSIGHT_DATA_PATH` is left
empty (the default), `src/data/loader.py::load_dataset` generates a
reproducible **synthetic** dataset matching the Cleveland heart disease
schema. The synthetic generator is documented in
`src/data/loader.py::generate_synthetic_dataset`.

The synthetic dataset is *not* real patient records and must never be
presented as such.

## Using a real dataset

To use the [UCI Heart Disease dataset](https://archive.ics.uci.edu/dataset/45/heart+disease)
(cleveland.data), place a CSV at this path and set the environment variable:

```bash
set CARDIOINSIGHT_DATA_PATH=data/heart_disease.csv
```

The CSV must have these columns (the Cleveland schema):

| Column | Description |
|---|---|
| age | age in years |
| sex | 0 = female, 1 = male |
| cp | chest pain type (0-3) |
| trestbps | resting blood pressure (mmHg) |
| chol | serum cholesterol (mg/dL) |
| fbs | fasting blood sugar > 120 mg/dL (1=true) |
| restecg | resting ECG (0-2) |
| thalach | maximum heart rate achieved |
| exang | exercise induced angina (1=true) |
| oldpeak | ST depression relative to rest |
| slope | slope of peak exercise ST segment (1-3) |
| ca | number of major vessels colored (0-3) |
| thal | thalassemia (0-3) |
| target | 0 = no disease, 1 = disease |

The schema is enforced by `src/data/schema.py::validate_schema`.
